**[AI Pronunciation Coach](https://github.com/ilyaolchikov/ai_pronunciation_coach)**

An experimental, local-first English pronunciation analysis application combining speech recognition, phoneme alignment and statistical calibration.

- Wav2Vec2-based speech processing
- Constrained CTC decoding and word-level analysis
- Calibrated feedback with explicit uncertainty
- Reproducible experiments and held-out evaluation

The project prioritises reliable feedback over confident but unsupported predictions. It is still experimental rather than learner-ready.
